SD Bridge

A Streamer.bot addon for directly switching the profile and page displayed on a Stream Deck.

→

⌘

Explore the source See how the single C# Core embeds plugin.js, icons, and the validation profile.
Designed to coexist with the official plugin SD Bridge does not replace the official Streamer.bot Stream Deck plugin. Its purpose is to add direct Stream Deck profile/page navigation from Streamer.bot.

What it does

Streamer.bot can interact with Stream Deck buttons, but the normal integration does not provide direct navigation between Stream Deck profiles and pages. SD Bridge adds that navigation layer.

Setup creates an editable [Bridge] copy of the selected profile:

"My Profile"
        ↓
"My Profile [Bridge]"

The [Bridge] version becomes the working profile you continue editing in the Stream Deck application. The live Bridge profile remains the source of truth when SD Bridge is updated later.

Installation

Import the Streamer.bot action

Use the Download Streamer.bot Action button in the Download panel on the right, then import the .sb file into Streamer.bot.

Setup / Update

The setup window scans the Stream Deck profiles available on the computer and separates them into existing Bridges and profiles that can be bridged.

Select the profile(s) to bridge

Choose the profile you want Streamer.bot to control. Existing [Bridge] profiles are preserved automatically.

Keep the validation profile for the first XL setup

If no live Bridge is detected on a Stream Deck XL setup, Bridge Validation Test is selected by default so both profile switching and page switching can be verified.

Generate the companion plugin

Click Generate plugin or Update plugin. SD Bridge creates the companion .streamDeckPlugin package and opens it automatically.

Confirm the plugin installation

Stream Deck first asks whether you want to install the SD Bridge plugin. Click Install.

Install the preconfigured profile(s)

If the generated package contains preconfigured profiles — for example the recommended Bridge Validation Test profile — Stream Deck displays a second prompt. Click Install Profile(s). The WPF then watches for the imported profile copies and checks their page structure.

Exact profile name Need the exact value for sdBridge.profile? Use Copy name in the WPF.

Validation

Once the imported profiles are detected and their page structure matches the generated package, the WPF enables the validation sequence.

  1. Click Start test.
  2. Watch the physical Stream Deck switch across several profiles and pages.
  3. The sequence returns to the first real [Bridge] profile.
  4. Confirm with Yes, everything worked if the result is correct.
If the validation fails Click No / something was wrong, complete the short questionnaire, and create the diagnostic report. The .txt report is generated on the Desktop and no original profile is removed.

Cleanup

After a successful full validation, SD Bridge offers two independent cleanup choices:

  • Original non-bridged profile(s) — keep them or remove them.
  • Bridge Validation Test — keep it for later testing or remove the temporary test profile.

Remove now closes Stream Deck when required, creates and verifies a safety backup, removes the selected data, and restarts Stream Deck when possible.

After conversion Work in the [Bridge] profile. Re-running Setup / Update updates the same Bridge rather than creating [Bridge] [Bridge].
Usage›SwitchPage

Using SwitchPage

The imported Streamer.bot package contains two example actions. Both eventually call the same public SwitchPage() method in the SD Bridge Core.

C#
C# example Edit two variables in a short wrapper and call the Core method.
SA
Sub-Actions example Set two Streamer.bot arguments without editing C#.

C# example

0x - Streamer.bot StreamDeck Plugin Addon - SwitchPage Exemple (with C#)

Edit the profile and page values in the example:

string profile = "My Profile [Bridge]";
string page = "JDR";

The wrapper sets the expected arguments and calls the Core's SwitchPage() method.

Sub-Actions example

0x - Streamer.bot StreamDeck Plugin Addon - SwitchPage Exemple (with Sub-Actions)

Edit the first two Set Argument sub-actions:

sdBridge.profile = My Profile [Bridge]
sdBridge.page = JDR

The final Execute C# Method → SwitchPage sub-action sends those values to the Core. No C# editing is required.

Arguments

ArgumentValue
sdBridge.profileExact Bridge profile name, stable key, or known alias.
sdBridge.pageExact page name or a 1-based page number.

Examples:

sdBridge.profile = My Profile [Bridge]
sdBridge.page = JDR

sdBridge.profile = My Profile [Bridge]
sdBridge.page = 2
Reference›Source code

Source code

The source is published in the GitHub repository for transparency and maintainability. It is not required for normal SD Bridge use.

The official SD Bridge logo is locked as the canonical identity and is included under src/branding/ in PNG, SVG and ICO formats. The WPF, Stream Deck plugin and website all use that same final logo.

The main reason readable source files are kept alongside the single-file C# Core is that the Core embeds the Stream Deck companion assets as Base64. Publishing their readable counterparts makes it possible to inspect, modify, and verify what is actually embedded.

Readable sourceEmbedded / generated form
src/plugin/bin/plugin.jsPluginJsBase64
src/plugin/imgs/plugin/icon.pngPluginIconBase64
src/plugin/imgs/actions/bridge/icon.pngActionIconBase64
src/validation-profile/Bridge_Validation_Test_SOURCE.streamDeckProfileValidationProfileBase64

The Stream Deck manifest.json is generated dynamically by the C# Core because the plugin version and Bridge profile entries depend on the current setup. manifest.template.json is provided as a readable reference.

Origin & credits

SD Bridge was originally built from the official Streamer.bot Stream Deck plugin and extends that work with the Bridge profile workflow and direct profile/page navigation.

Original plugin credit The official Streamer.bot Stream Deck plugin was created by Whipstickgostop ↗. SD Bridge is a separate community derivative and does not replace the official plugin.
